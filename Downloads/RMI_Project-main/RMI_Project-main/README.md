This project is a Final Year Project (PFE) that focuses on the development of a web-based logistics and distribution management system designed for companies managing multiple warehouses, suppliers, transporters, and points of sale.

The main objective of the system is to automatically generate an optimized distribution plan, helping companies organize deliveries efficiently while considering real-world constraints such as warehouse locations, supplier–store relationships, available vehicles, and delivery routes.
